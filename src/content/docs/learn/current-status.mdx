## Implemented foundations

- Runtime lifecycle, platform, task, diagnostic, and surface-outcome foundations.
- A `wgpu`-backed RHI behind Meridian-owned contracts and a render graph.
- Penumbra direct PBR, cascaded shadows, diffuse irradiance IBL, extraction, upload, pass timing, capture, and bounded GPU smokes.
- Transactional source import plus bounded asset, package, streaming, world activation, save, and recovery paths.
- Meridian UI core proof plus bounded Creator source, session, transaction, play, recovery, UI, and build foundations.
- A transitional Rapier-backed physics wrapper and grounded-controller foundation.
- An Alluvium implemented foundation with canonical text recipes, strict scalar evaluation, stable generated identity, cache recovery, CLI work, and a basic inspector.
- A partial native-modeler foundation with bounded editable-model source, stable topology lineage, semantic recovery, and a derived preview.

## Active and still unqualified

Meridian UI packages `WP-UI-002` through `WP-UI-004` have locally implemented
foundations but do not yet have the required cross-platform qualification.
`WP-UI-005` is the active package for motion, accessibility, effects, and
renderer qualification. Local implementation or a private source revision does
not make those packages a complete Meridian UI framework or a visual-quality
claim.

## Not complete

The production Penumbra Forward+ path, full creator workflows, broader native modeler, Rust gameplay modules, optional Luau, animation, navigation, frameworks, first-class 2D, Meridian Shader Language, Wavefront runtime, Collective, native graphics backends, and the Project Meridian prototype remain incomplete.

Some named crates are scaffolds. Their presence in the workspace is not a runtime feature claim.

## What the next revision may change

Status moves package by package. A newer source revision can close evidence or narrow a boundary without changing the architecture’s long-term direction. The provenance block above records exactly which snapshot this page describes.
