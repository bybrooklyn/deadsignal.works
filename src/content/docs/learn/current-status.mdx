## Implemented foundations

- Runtime lifecycle, platform, task, diagnostic, and surface-outcome foundations.
- A `wgpu`-backed RHI behind Meridian-owned contracts and a render graph.
- Penumbra direct PBR, cascaded shadows, diffuse irradiance IBL, extraction, upload, pass timing, capture, and bounded GPU smokes.
- Transactional source import plus bounded asset, package, streaming, world activation, save, and recovery paths.
- Meridian UI foundations and bounded Creator Alpha source, session, transaction, play, recovery, UI, and build behavior.
- A transitional Rapier-backed physics wrapper and grounded-controller foundation.
- Partial Alluvium text recipes, strict scalar evaluation, cache recovery, CLI, and basic inspector work.

## Not complete

The production Penumbra Forward+ path, full creator workflows, native modeler, Rust gameplay modules, optional Luau, animation, navigation, frameworks, first-class 2D, Meridian Shader Language, Wavefront runtime, Collective, native graphics backends, and the Project Meridian prototype remain incomplete at this snapshot.

Some named crates are scaffolds. Their presence in the workspace is not a runtime feature claim.

## What the next revision may change

Status moves package by package. A new public revision can close evidence, narrow a boundary, or make this page stale without changing the architecture’s long-term direction. That is why the date and source revision appear at the top of this page.
