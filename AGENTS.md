# Dead Signal Works Website Agent Policy

## Branch discipline

- Work only on `main` in this repository. Before changing files, verify the current branch is `main`.
- Never create or switch to another branch, commit or push from another branch, create a worktree on another branch, or open a pull request from another branch.
- If repository rules or permissions prevent direct work on `main`, stop and ask the user to resolve the restriction. Do not use another branch as a workaround.
