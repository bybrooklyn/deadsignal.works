# Dead Signal Works auth.md

Dead Signal Works is a public static website. This domain does not expose a
protected API, OAuth or OpenID Connect issuer, credential-registration
endpoint, or agent-registration flow.

Public pages and documentation do not require credentials. Agents should use
the canonical links and read-only discovery tools published by this site. Do
not send credentials to this domain on the assumption that an authentication
service is available.

Alchemist is a separate self-hosted application. Its mirrored documentation
describes that application's local authentication model; it is not an
authentication service hosted by deadsignal.works.
